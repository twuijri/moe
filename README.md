# 🏫 نظام واتس اب المدارس (WhatsApp School SaaS)

نظام متكامل لإدارة مراسلات المدارس عبر واتساب، يدعم الحملات الإعلانية، إدارة الطلاب، وتخصيص هوية المدرسة.

## ✨ المميزات
- 🚀 **إرسال حملات واتساب**: إرسال رسائل لآلاف الطلاب بضغطة زر.
- 📱 **مسح الباركود**: ربط سهل مع واتساب ويب.
- 📂 **إدارة الطلاب**: استيراد من Excel وإضافة يدوية.
- 🎨 **هوية مخصصة**: إمكانية تغيير اسم الموقع والشعار من لوحة التحكم.
- 🛡️ **أمان البيانات**: تخزين محلي للبيانات مع دعم النسخ الاحتياطي (Docker Volumes).
- 📊 **سجلات وتقارير**: متابعة دقيقة لكل رسالة (تم الإرسال / فشل) مع إمكانية تصدير السجلات.

---

## 🛠️ متطلبات التشغيل (Server Requirements)
- خادم (Server) يعمل بنظام Linux (Ubuntu/Debian) أو أي نظام يدعم Docker.
- **Docker** و **Docker Compose** مثبتين.

---

## 🚀 طريقة التثبيت والنشر (Installation & Deployment)

### 1. سحب المشروع من GitHub
ادخل على السيرفر واسحب الكود:
```bash
git clone https://github.com/twuijri/moe.git
cd moe
```

### 2. تشغيل النظام
كل ما عليك فعله هو تشغيل هذا الأمر، وسيقوم النظام ببناء نفسه وتشغيل قاعدة البيانات تلقائياً:
```bash
docker-compose up --build -d
```
*ملاحظة: إذا ظهر لك خطأ "command not found"، جرب الأمر الجديد:*
```bash
docker compose up --build -d
```

### 3. الدخول للنظام
النظام يستخدم منفذ (Port) عشوائي متاح تلقائياً لتجنب التعارضات.
لمعرفة المنفذ المخصص، استخدم الأمر:
```bash
docker compose ps
```
أو
```bash
docker-compose ps
```
ستجد رقم المنفذ بجانب `0.0.0.0:XXXXX->3000/tcp`

افتح المتصفح وادخل على:
`http://YOUR_SERVER_IP:XXXXX`
(استبدل XXXXX برقم المنفذ الذي ظهر لك)

### 🏗️ بيانات الدخول الافتراضية
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`
*(يرجى تغييرها فوراً من لوحة تحكم المشرفين)*

---

## 💾 النسخ الاحتياطي (Backups)
النظام يستخدم **Docker Volumes** لحفظ البيانات بشكل آمن ومستقل عن الحاوية.

- **قاعدة البيانات**: محفوظة في `watsapp-google_whatsapp_data`
- **الجلسة (Session)**: محفوظة في `watsapp-google_whatsapp_session`

لأخذ نسخة احتياطية من مجلد البيانات (يشمل الداتا بيس):
يمكنك العثور على مسار الفوليوم عبر:
```bash
docker volume inspect watsapp-google_whatsapp_data
```
عادة يكون المسار: `/var/lib/docker/volumes/watsapp-google_whatsapp_data/_data`

---

## 🧹 تجهيز نسخة لعميل جديد (Factory Reset)
إذا أردت تسليم النظام لعميل جديد "نظيف" تماماً (بدون بياناتك أو شعارك):

1. شغل سكريبت التنظيف المرفق:
```bash
chmod +x prepare_for_client.sh
./prepare_for_client.sh
```
2. سيقوم هذا الأمر بحذف قاعدة البيانات والشعارات المخصصة وإفراغ النظام.
3. يمكنك الآن ضغط المشروع وإرساله أو إعادة تثبيته.

---

## ⚠️ حل المشاكل
- **نسيت كلمة المرور؟**
  احذف ملف قاعدة البيانات (أو الفوليوم) وسيعيد النظام إنشاء حساب `admin` الافتراضي عند إعادة التشغيل.
- **الواتساب فصل؟**
  اضغط زر "خروج" أو أعد تشغيل الحاوية `docker-compose restart app` وامسح الباركود من جديد.
